# 📊 VOYX Sales Dashboard

> 🚀 An interactive sales analytics dashboard designed to monitor sales performance, revenue, targets and team productivity in one place.

---

## ✨ Overview

**VOYX Sales Dashboard** is a web-based analytics dashboard that provides a clear view of sales performance through interactive KPIs, charts, leaderboards and destination-wise insights.

It connects with **Supabase** to fetch dashboard data and uses **Chart.js** for dynamic data visualization.

---

## 🎯 Key Features

📈 **Sales Performance**
- Daily sales performance
- Month-to-date (MTD) performance
- Previous month comparison

🏆 **Sales Leaderboard**
- Sales representative ranking
- Performance comparison
- Target vs achievement insights

🌍 **Destination Analytics**
- Top-performing destinations
- Destination-wise sales insights

📊 **Interactive Charts**
- Daily sales trends
- Monthly sales trends
- Dynamic data visualization using Chart.js

📅 **Date-Based Dashboard**
- Select a report date
- View performance for the selected period

📥 **CSV Export**
- Download sales leaderboard data as CSV

🔄 **Real-Time Data Integration**
- Supabase REST API integration
- Dynamic dashboard data loading
