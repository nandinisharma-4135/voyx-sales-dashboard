# VOYX Sales Dashboard

An interactive sales analytics dashboard for monitoring sales performance, revenue, targets and sales representatives.

## Features

- Daily sales performance
- Monthly sales performance
- Sales representative leaderboard
- Top destinations
- Daily and monthly charts
- Date-based dashboard
- CSV leaderboard download
- Supabase API integration
- Responsive dashboard interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Supabase

## Project Overview

VOYX Sales Dashboard provides an admin-style interface to monitor sales performance through KPIs, charts, leaderboards and destination analytics.
